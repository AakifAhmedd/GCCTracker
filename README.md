# Guide Club Tracker

A lightweight tracker for the Rotaract Clubs of Colombo Fort and Colombo West, covering RI Year 2026–27 in Sri Lanka and the Maldives.

Track mandatory requirements and deadlines, avenue and optional citations, project evidence, and progress towards Bronze, Silver, Gold, and Platinum tiers. Compare both clubs in the overview.

## Getting started

Open `gccTracker.html` in a browser. No installation or build step is needed; Google Fonts load from the internet.

1. Select a club and review its dashboard.
2. Mark completed requirements and add notes.
3. Log projects with their avenue, date, RMIS status, and evidence references.

## Saving your work

Changes save automatically in this browser's local storage. Use **Export data (JSON)** for backups or to move your records to another device. **Import data (JSON)** replaces the current records for both clubs; it does not merge them.

The displayed scores follow the rules built into the app. Requirements, deadlines, and scoring are defined in `gccTracker.html`.
